# panel-data

Це не гілка коду. Тут лежить те, що редагує панель керування:

| Файл | Що це |
|---|---|
| `content.json` | Тури й відгуки, які показує сайт |
| `pending.json` | Відгуки від відвідувачів, які чекають на вашу перевірку |
| `config.json` | Хеш пароля панелі та ключ підпису сесій |
| `media/…` | Фото й відео, завантажені через панель |

Гілка навмисно не має спільної історії з `main` і **не деплоїться**. Функції
сайту читають і пишуть ці файли через GitHub API, тому збереження в панелі не
запускає збірку — зміни з'являються на сайті самі.

Правити тут щось руками можна, але обережно: панель перезапише файл цілком при
наступному збереженні. Якщо треба відкотити зміну — історія комітів цієї гілки
і є історія змін вмісту.

**`config.json` містить секрет.** Тому репозиторій має лишатися приватним.
